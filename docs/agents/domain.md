# Domain docs

Use a single-context layout: `GLOSSARY.md` at the repository root
and decisions under `docs/adr/`.

## Before exploring

Read the local glossary, when present, and ADRs relevant to the work.
Shared GETQUICK terms are defined in
[gq-platform's glossary](https://github.com/Quick-Release/gq-platform/blob/main/GLOSSARY.md),
as established by AGENTS.md.

If local domain documents are absent, proceed silently.
Domain modeling creates them as terms and decisions are resolved.

## Vocabulary and decisions

Use the glossary's terms in issues, specifications, code and tests.
Keep shared terminology in gq-platform; record content-runtime
terminology and decisions here.

Surface conflicts with an existing ADR explicitly, naming the ADR
and explaining the proposed change.
