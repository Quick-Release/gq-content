# 0.6.1: GQ Design 0.10.4

Release `@getquick/content` and `getquick/gq-content` together from one retained
`v0.6.1` candidate. The prior stable pair was 0.6.0. Wire contract 2.1.0 is
unchanged; no publication-store or consent migration is added.

- **Design 0.10.4:** the bundled `@quick-release/design-renderer` and
  `@quick-release/design-contract` move from 0.10.2 to 0.10.4. 0.10.3 was never
  published.
- **Lists keep their markers** (gq-design#127, #129, ADR 0004 amendment): the
  bundled presentation model no longer defaults `core/list` to
  `list-style-type:none`. `presentationStyleSheet(theme)` gives an unauthored
  `ul.wp-block-list` a `disc` marker and an `ol.wp-block-list` a `decimal` one,
  inside the box. The defaults are in `:where()`, so an authored list style
  type or position, including `none`, still wins.

## Release gates and rollout

The required PR checks and the retained paired validation workflow must pass.
Publish only from the successful CI record, as in [releasing](../releasing.md);
the operator probe requires GQ Design 0.10.4's Composer record.

A Site adopts it through the blueprint: bump the `@getquick/content` and
`getquick/gq-content` pins to 0.6.1 and GQ Design to 0.10.4, `gq sync`, rebuild
and deploy. Lists authored without a marker style now show disc or decimal
markers; set the list style type to `none` where a list should stay bare.
