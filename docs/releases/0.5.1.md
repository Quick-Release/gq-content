# 0.5.1: GQ Design 0.10.2

Release `@getquick/content` and `getquick/gq-content` together from one retained
`v0.5.1` candidate. The prior stable pair was 0.5.0. Wire contract 2.1.0 is
unchanged; no publication-store or consent migration is added.

- **Design 0.10.2:** the bundled `@quick-release/design-renderer` and
  `@quick-release/design-contract` move from 0.10.1 to 0.10.2.
- **Plain headings take the text styles' sizes** (gq-design#121): the bundled
  presentation model has no `core/heading` typography defaults, so
  `presentationStyleSheet(theme)` no longer forces `inherit !important` on a
  heading's font family, size, weight, line height or letter spacing unless the
  heading authors them. The text styles' heading rules (for example
  `h1{font-size:var(--gqd-text-5xl)}`) now apply; authored values still win.
- **Slot stacks on the content root from GQ Design** (gq-design#117, #118):
  `designFontStyleSheet` passes the content root to `fontStyleSheet`, which
  emits the stacks on `:root,.gqd-content.gqd-content` (or `:root,<root><root>`).
  0.5.0's workaround that re-parsed the `:root{…}` block is removed.
  `designFontsHead` keeps its order and output contract.
- **Invalid text style values** (gq-design#119): a bad stored value is dropped
  from the text styles instead of throwing during a page render.

## Release gates and rollout

The required PR checks and the retained paired validation workflow must pass.
Publish only from the successful CI record, as in [releasing](../releasing.md);
the operator probe requires GQ Design 0.10.2's Composer record.

A Site adopts it through the blueprint: bump the `@getquick/content` and
`getquick/gq-content` pins to 0.5.1 and GQ Design to 0.10.2, `gq sync`, rebuild
and deploy. No design refresh is needed.
