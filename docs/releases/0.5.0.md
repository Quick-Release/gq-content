# 0.5.0: GQ Design fonts and text styles, Design 0.10.1

Release `@getquick/content` and `getquick/gq-content` together from one retained
`v0.5.0` candidate. The prior stable pair was 0.4.2. No publication-store or
consent migration is added: fonts and text styles are optional members of the
stored design presets, so presets stored by 0.4.x stay readable.

- **Design 0.10.1:** the bundled `@quick-release/design-renderer` and
  `@quick-release/design-contract` move from 0.9.4 to 0.10.1 (wire contract
  2.1.0, additive over 2.0.0). Both contract versions' tokens are read.
- **Fonts and text styles in the design presets:** the `DesignPresets` read
  also asks WPGraphQL for `designTokens { fonts textStyles }`. A CMS whose GQ
  Design predates them (0.9.x, contract 2.0.0) rejects the fields; the presets
  are read again without them, with a warning. `runtime.designPresets()` and
  served pages carry the optional `fonts` and `textStyles`.
- **`designFontsHead(presets, { root? })`** (`@getquick/content`): the head
  markup for them: at most two `<link rel="preload" as="font" type="font/woff2"
  crossorigin>`, the `@font-face` rules with their metric-matched fallbacks and
  the slot stacks, then the Heading and Paragraph text styles. Empty without
  fonts or text styles, or with no families. Faces with a relative or Google URL
  are dropped. `designFontStyleSheet`, `designFontPreloads` and
  `designTextStyleSheet` return the parts. The slot stacks are also set on the
  content root, where the theme stylesheet would otherwise keep the system stack.
- **CMS settings events:** GQ Design's font slot assignments
  (`getquick_design_font_slots`) and Font Library families and faces
  (`wp_font_family`, `wp_font_face`) saved or deleted send the `design` event.
  Text styles are saved in the global styles, which already sent it.

## Release gates and rollout

The required PR checks and the retained paired validation workflow must pass.
Publish only from the successful CI record, as in [releasing](../releasing.md);
the operator probe requires GQ Design 0.10.1's Composer record.

A Site adopts it through the blueprint: bump the `@getquick/content` and
`getquick/gq-content` pins to 0.5.0 (and GQ Design to 0.10.1, without which
there are no fonts to render), emit `designFontsHead` after the theme stylesheet
in the layout, `gq sync`, rebuild and deploy, then send a `design` refresh (or
let reconciliation run) so the stored presets gain the fonts. Cross-origin font
files on a media host load only once that bucket has a public CORS rule.
