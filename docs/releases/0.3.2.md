# 0.3.2: canonical Design presentation and media lifecycle

Release `@getquick/content` and `getquick/gq-content` together from one retained
`v0.3.2` candidate. npm's latest and the prior GitHub pair were both 0.3.1 when
this fix release was prepared. No publication-store migration is added.

For the new presentation contract, deploy the published Design 0.9.0 pair
(wire 2.0.0 / storage 1). Its exact published contract/renderer are build inputs,
bundled into content; Sites install no managed renderer dependency. See
[published input provenance](../evidence/tailwind-presentation/published-design-0.9.0.md).

Presentation/theme helpers and typed delivery cover neutral patterns, parsed
blocks and ordinary HTML. Shared browser entry `@getquick/content/design/client`
exports Carousel, navigation, Hero and decorative Cover initializers. Wire their
cleanup/remount into the Site's existing page lifecycle. Cover videos no longer
start before reduced-motion preferences are known; native delivered Polylang
selects work without executing inline scripts. Query rendering uses preloaded
producer-selected standard Post/Page contexts through the existing reader.

ADR 0004 replaces old appearance fields and Grid device presets; this release
adds no appearance compatibility resolver or wire-1 fallback. Saved native HTML
and current neutral controls retain their separately documented semantics.
Supplied Site/post/media contexts and local playable-video cases are supporting
evidence, not additional saved CMS producer captures. See the
[bounded matrix](../evidence/tailwind-presentation/README.md).

## Release gates and rollout

Required PR checks and the retained paired validation workflow must pass. Build
once, validate that exact npm/ZIP pair, then publish only with the successful CI
record via `node scripts/release.mjs publish BUNDLE CI_RUN`. The operator wrapper
maps only approved in-memory Sigillo Composer/npm credentials and the validated
GitHub operator credential; it does not weaken these gates. Registry credentials
must never be passed through command arguments, written to disk or logged.

A partial npm/Composer publication blocks adoption. Verify both 0.3.2 packages
are installable before the Blueprint pin update and Site update/deployment.
Nomia's owner owns its update/deploy; this repository does not mutate Site content.

Approved operator transport injects `COMPOSER_AUTH` and `NPM_TOKEN` per command.
`scripts/release/operator.mjs probe` selects only the existing
`proxy.composer.getquick.io` HTTP-basic entry in memory, verifies the operator's
registry repository push capability, checks published Design 0.9.0 in Composer
and authenticates npm. `publish BUNDLE CI_RUN` invokes the unchanged retained
release gate with scoped aliases. The npm configuration contains a literal token
placeholder and is removed afterward; it contains no token value. No secret
scope credentials or project bootstrap keys are copied into the release child.
