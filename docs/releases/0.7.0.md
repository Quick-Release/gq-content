# 0.7.0: Embed consent services and gradient presets

Prepare `@getquick/content` and `getquick/gq-content` together from one retained
`v0.7.0` candidate. The prior stable pair is 0.6.2. This release contains
[PR #67](https://github.com/Quick-Release/gq-content/pull/67), merged as
`519effe`. GQ Design stays at 0.10.4 (the pair accepts 0.10.x); there is no SQL
migration.

## Consent catalog

Three `external_media` services join the closed catalog. A Site declares them in
`consent.services`; until it does, their iframes stay blocked placeholders.

- `viewmedica`: ViewMedica patient-education videos (Swarm Interactive, Inc.),
  embeds from `ondemand.viewmedica.com`.
- `valet_health`: Valet Health forms and surveys (Valet Metrix, LLC, d/b/a
  Valet Health, on HighLevel's LeadConnector), embeds from
  `link.valethealth.com/widget/form/` and `/widget/survey/`.
- `reputationhub`: HighLevel Reputation Hub review widgets, embeds from
  `reputationhub.site/reputation/widgets/`.

Declaring a new service in a granted category prompts visitors again, as any
material configuration change does.

## Gradient presets

The CMS plugin adds WPGraphQL's `getquickGradients { slug gradient }`, built from
the merged `settings.color.gradients`. The Frontend reads it in the same
`DesignPresets` request and stores it with the shared design presets as
`gradients`; every page is served with it. `blockPresetStyles(presets, scope?)`
and `presetRootStyle(presets)` take a page's presets and emit
`--wp--preset--gradient--<slug>` and `.has-<slug>-gradient-background`. The
positional forms still work, with gradients last. A Frontend on 0.7.0 reading an
older CMS plugin stores presets without gradients and logs a warning. Deploy the
CMS plugin first, then refresh the design presets (`gq frontend refresh`, or any
design settings event) so the stored presets gain them.

## Release gates and rollout

This document prepares a candidate; it does not by itself declare publication
complete. Follow [the stable release policy](../releasing.md): owner review,
successful retained paired CI validation, separate publication authorization,
then publication of the exact CI bundle. Verify that the npm and Composer
artifacts match and are immutable; a partial publication blocks Blueprint
adoption. The Blueprint owns the managed pair pins.
